# Icon colors

The `icon-context` collection has one variable, `--ds-icon-color-icon-context`, with a value per context. `primary` is the default on `:root`; any element can switch the context for everything inside it with `data-icon-context="<context>"`. Icons are drawn in `currentColor` and set `color: var(--ds-icon-color-icon-context)`.
