# Colors

<FoundationContent page="colors" />

Semantic colors from the `semantics` collection, grouped by role. Each swatch shows its value, the primitive it aliases, and its contrast against `text-primary` and `text-inverse`. Components and blocks use these only.

{[...groupBy(varsWhere('--ds-color-', 'semantics'), '--ds-color-')].map(([group, names]) => (
  <section key={group}>
    <h2>{group}</h2>
    <ColorSwatches names={names} />
  </section>
))}

## Primitives (reference only)

The raw palette the semantic colors point at. Not allowed in components or blocks.

{[...groupBy(varsWhere('--ds-color-', 'primitives'), '--ds-color-')].map(([group, names]) => (
  <section key={group}>
    <h3>{group}</h3>
    <ColorSwatches names={names} against={[]} />
  </section>
))}
