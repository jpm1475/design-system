# Colors

Semantic colors from the `semantics` collection. Components and blocks use these only; never the primitives below them.

{[...groupBy(varsWhere('--ds-color-', 'semantics'), '--ds-color-')].map(([group, names]) => (
  <section key={group}>
    <h2>{group}</h2>
    <Swatches names={names} />
  </section>
))}

## Primitives (reference only)

The raw palette the semantic colors point at. Not allowed in components or blocks.

{[...groupBy(varsWhere('--ds-color-', 'primitives'), '--ds-color-')].map(([group, names]) => (
  <section key={group}>
    <h3>{group}</h3>
    <Swatches names={names} />
  </section>
))}
