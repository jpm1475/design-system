# Typography

<FoundationContent page="typography" />

Type roles from the `typography-semantics` collection, set in THICCCBOI from `@jpm1475/ds-fonts`. Resize the viewport (toolbar) to see each breakpoint: the values change through media queries in `tokens.css`, so components never need their own font-size media queries.

Each role has five variables: `--ds-type-<role>-font-family`, `-font-weight`, `-font-size`, `-line-height` and `-letter-spacing`. The line under each sample shows font size, line height and weight per breakpoint.
