Purpose-based color tokens that alias primitives. Each token is scoped to its intended property.

- **Text:** text fill colors. Controls all body copy, headings, labels and captions.
- **Icon:** icon and vector fill colors. Controls all iconography and vector artwork.
- **Surface:** background and surface fill colors. Controls frames, cards, sections and overlays.
- **Border:** stroke and border colors. Controls outlines, dividers and separators.
- **Interactive:** interactive element colors. Controls buttons, links and interactive surfaces.
- **Feedback:** feedback and status colors. Controls alerts, badges, toasts and validation states.
