# Elevation

<FoundationContent page="elevation" />

Each elevation level is composed from its Figma variables (x offset, y offset, blur, spread, color) into one `box-shadow` value, `--ds-elevation-l<n>`. Components use only these composites for shadows, and only `--ds-z-*` for stacking.
